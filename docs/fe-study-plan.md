## 科目Bの鉄則（自分の失点から）

1. **式を変形したくなったら、道を外れている。** 科目Bは数学ではない。
   問われているのは「このコードを動かすと何が起きるか」だけ。
2. **小さい具体値を入れて動かす。** n=10 くらいを突っ込めば数行で挙動が見える。
   抽象的に考えるより速くて確実。
3. **難しく見える問題ほどトレースに戻る。** 簡単な問題は頭でも解けるが、
   難しい問題でトレースをやめると必ず落ちる。人間は逆をやる（2026-09-12 問5）。
4. 配列は **1始まり**。Pythonの0始まりの癖で数えない。
5. 選択肢を先に読まない。読むと脳が消去法に切り替わって、トレースをやめる。
