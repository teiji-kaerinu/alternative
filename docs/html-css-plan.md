## 方針：上手くなることが目的ではない

目的は **Flask本体の足を引っ張らないラインまで上げて、そこで止めること。**

HTML/CSSは終わりがない代わりに、このアプリに必要な分は驚くほど少ない。
「習得してから作る」の順にすると、終わりのないものに終わりを待つことになる。

| 段階 | 中身 | このプロジェクトでの扱い |
|---|---|---|
| ① 読める | 他人のHTML/CSSを見て何がどう効いてるか分かる | **やる**（PHASE 00） |
| ② 組める | 白紙から画面5枚のガワを作れる | **やる**（実装しながら） |
| ③ デザインできる | 崩れないレイアウトを設計する・美しく作る | **やらない。スコープ外** |

F2〜F3は実質ぜんぶフォーム。`Spot` の列（name / work / address / lat / lng /
scene_note / priority）がそのまま入力項目になるので、ここで書いた下書きは

なお Flask-WTF がHTMLを吐くので **「白紙から書ける」までは本来不要**。
それでも手で一度書くのは、吐かれたHTMLを読んでデバッグできるようにするため。

## 到達判定（10/25まで）

この3つが言えたら終わり。それ以上は伸ばさない。

1. 「このCSSが効かない」の原因を、DevToolsで5分以内に特定できる
2. 白紙から入力フォームを書ける（`form` / `label` / `input` / `button` の対応が手癖）
3. 375pxで崩れたとき、疑うべきプロパティを3つ挙げられる

## 禁止事項と、その理由

| 禁止 | 理由 |
|---|---|
| **色とフォントを選び直す** | 絵描きの最大の地雷。「なんか気に入らない」で溶ける時間に上限がない。`#1a1a2e` / `#16213e` / `#8b7bff` で確定。解禁は12/7のPHASE 03だけ、上限3時間 |
| 入門サイトをもう一周する | 合宿明けに必ずやりたくなる。忘れてるのは当然で、忘れていない部分だけが本当に要る部分 |
| Bootstrap / Tailwind / React を入れる | 覚える時間のぶん佐渡に間に合わなくなる。素のCSSで画面5枚は足りる |
| CSS設計（BEM等）を学ぶ | 設計が要るのは画面が何十枚もあるとき。5枚に設計は要らない |
| アニメーション・ホバー演出 | DoDに入っていない。READMEの「今後やりたいこと」行き |
| JavaScriptを先に勉強する | F5（Leaflet）に着手する日に2時間取れば足りる。それまでゼロでいい |
