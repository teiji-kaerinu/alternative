8-1. ネットワークの応用技術

VPN(Virtual Private Network)

公衆回線を使いながら、あたかも専用線のように安全に通信する技術。 通信を暗号化して包むトンネリングが基本。

種類特徴
インターネットVPNインターネットを経由する。安いが品質は保証されない
IP-VPN通信事業者の閉域網を使う。高品質・高価
IPsec-VPNネットワーク層で暗号化。拠点間接続に向く
SSL-VPNブラウザだけで使える。在宅勤務など個人の接続に向く

IPsec は AH(認証のみ)と ESP(暗号化+認証)からなる。 通信全体を包むトンネルモードと、データ部だけ暗号化するトランスポートモードがある。

プロキシサーバ

  • フォワードプロキシ … 社内から外へのアクセスを代理する。 アクセス制御・ログ取得・キャッシュによる高速化ができる
  • リバースプロキシ … 外から社内サーバへのアクセスを代理する。 負荷分散やSSL処理の肩代わりに使う

その他

用語意味
CDNコンテンツを世界中のキャッシュサーバに置き、利用者に近い場所から配信する。 大容量配信の高速化と本体サーバの負荷軽減
ロードバランサ負荷分散装置。複数サーバへリクエストを振り分ける
SDNソフトウェアでネットワーク構成を柔軟に制御する技術(OpenFlowなど)
IP電話(VoIP)音声をパケット化してIP網で送る。制御はSIP、音声転送はRTP
テザリングスマホを経由してPCなどをインターネットに繋ぐ
MVNO他社の回線設備を借りて通信サービスを提供する事業者(格安SIM)
LPWA低消費電力で広範囲に届く無線。IoTセンサ向け。速度は遅い
BLEBluetooth Low Energy。省電力の近距離無線
ビーコン電波を発信して位置情報などを提供する小型機器

8-2. ネットワークセキュリティ

ファイアウォール

内部と外部の境界に置き、通してよい通信だけを許可する関所。

方式見るもの特徴
パケットフィルタリングIPアドレス・ポート番号単純で高速。パケット1個ずつ独立に判断する
ステートフルインスペクション通信の状態(セッション)行きの通信を覚えていて、その戻りだけを通す。より安全
アプリケーションゲートウェイデータの中身プロキシ型。細かく制御できるが遅い

DMZ(非武装地帯)

外部にも内部にも属さない中間地帯。 Webサーバやメールサーバなど外部に公開するサーバを置く。

[インターネット] ── FW ── [ DMZ ] ── FW ── [ 社内LAN ] Webサーバ 重要データ メールサーバ 社員PC DNSサーバ ねらい:公開サーバが乗っ取られても、社内LANまでは侵入されない

SSL/TLS

  • 通信を暗号化するプロトコル。HTTPと組み合わせたものが HTTPS(ポート443)
  • ハイブリッド暗号方式を使う … 公開鍵暗号で共通鍵を安全に配り、実際のデータは高速な共通鍵暗号で暗号化する
  • サーバ証明書を認証局(CA)が発行し、「このサイトは本物」であることを保証する
  • できること … 盗聴防止(暗号化)・改ざん検知・なりすまし防止(認証)

検知・防御の仕組み

名前役割
IDS侵入検知システム。不正を見つけて知らせるだけ
IPS侵入防止システム。見つけて遮断までする
WAFWebアプリ専用の防御。SQLインジェクションやXSSを防ぐ
SIEM各機器のログを集めて相関分析し、攻撃の兆候を見つける
IDS と IPS の違いは頻出。「Detection = 検知(知らせるだけ)」「Prevention = 防止(止める)」。

代表的な攻撃

攻撃内容
DoS / DDoS大量のリクエストを送りつけてサービスを停止させる。 DDoSは多数の端末から一斉に行う
中間者攻撃通信の間に割り込んで盗聴・改ざんする
DNSキャッシュポイズニングDNSに偽の対応を覚えさせ、偽サイトへ誘導する
ARPスプーフィング偽のARP応答を流し、通信を自分に引き込む
ポートスキャン開いているポートを調べ上げ、侵入口を探す下調べ
SQLインジェクション入力欄に不正なSQLを混ぜてデータベースを操作する
XSS他人のサイトに悪意あるスクリプトを埋め込む

8-3. 信頼性を高める(冗長化)

  • 二重化 / 冗長構成 … 同じ機器をもう1台用意し、壊れても止まらないようにする
  • リンクアグリゲーション … 複数のケーブルを束ねる。高速化 + 1本切れても継続
  • STP(スパニングツリー) … ループを防ぎつつ、障害時には迂回経路を有効にする
  • フェールオーバー … 障害時に待機系へ自動で切り替える
  • フォールトトレラント … 障害が起きても機能を落とさず動き続ける設計
  • フェールセーフ … 障害時に安全な側で停止する設計
  • フールプルーフ … 利用者が誤操作しても危険が起きないようにする設計
MTBF と MTTR。
MTBF(平均故障間隔) … 壊れずに動いていた平均時間
MTTR(平均修理時間) … 直すのにかかる平均時間
稼働率 = MTBF ÷ (MTBF + MTTR) … 計算は第9章で
