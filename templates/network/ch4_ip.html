4. IPアドレス

IPv4 アドレスの基本

  • 32ビット。8ビットずつ4つに区切り、10進数で 192.168.1.10 と書く
  • 8ビットで表せるのは 0〜255。だから各区切りは255以下
  • アドレスはネットワーク部とホスト部に分かれる
192.168. 1. 10 └─ ネットワーク部 ─┘└ ホスト部 ┘ 「どのネットワークか」 「その中の何番目か」

住所で言えば、ネットワーク部が「〇〇市〇〇町」、ホスト部が「3丁目5番地」。 同じネットワーク部を持つ機器同士は、ルータを通さず直接やり取りできる。

サブネットマスクと CIDR

サブネットマスクは「どこまでがネットワーク部か」を示す目印。 ネットワーク部を1、ホスト部を0で表す。

IPアドレス 192.168. 1. 10 サブネットマスク 255.255.255. 0 └─ 1が24個 ─┘└0が8個┘ → ネットワーク部24ビット = 「192.168.1.10/24」と書く(CIDR表記)

クラスに縛られず好きな位置で区切る方式を CIDR(サイダー)という。 「/24」の数字はネットワーク部のビット数。

特別な2つのアドレス

名前ホスト部意味
ネットワークアドレスすべて0そのネットワーク自体を指す。機器には割り当てられない
ブロードキャストアドレスすべて1そのネットワーク全員宛て。機器には割り当てられない
割り当て可能なホスト数 = 2^(ホスト部のビット数) − 2 この「−2」がネットワークアドレスと ブロードキャストアドレスの分。

例題1

192.168.10.0/26 のネットワークについて、サブネットマスク・割り当て可能なホスト数・ブロードキャストアドレスを答えよ。

① ホスト部のビット数 32 − 26 = 6ビット ② ホスト数 2^6 − 2 = 64 − 2 = 62台 ③ サブネットマスク 1が26個 → 255.255.255.192 (第4オクテット 11000000 = 192) ④ 区切りは64個刻み 0〜63 / 64〜127 / 128〜191 / 192〜255 ⑤ よって ネットワークアドレス 192.168.10.0 使えるアドレス 192.168.10.1 〜 192.168.10.62 ブロードキャスト 192.168.10.63

例題2

172.16.0.0/16 のネットワークを 8 個のサブネットに分割したい。サブネットマスクは?

① 8個に分けるには何ビット借りる? 2^3 = 8 → 3ビット ② ネットワーク部 16 + 3 = 19ビット → /19 ③ サブネットマスク 255.255.224.0 (第3オクテット 11100000 = 224)
2のべき乗を暗記しておくと速い。
21=2 / 22=4 / 23=8 / 24=16 / 25=32 / 26=64 / 27=128 / 28=256
マスクの第4オクテットは 128 / 192 / 224 / 240 / 248 / 252 / 254 / 255 のどれかにしかならない。

プライベートIPアドレス

組織内で自由に使ってよいアドレス。そのままではインターネットに出られないので、NAT/NAPT で変換する(→ 第7章)。
