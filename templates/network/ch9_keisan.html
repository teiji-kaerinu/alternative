9-1. 伝送時間の計算

伝送時間 = データ量(ビット) ÷ 実効速度(bps) 実効速度 = 回線速度 × 回線利用率(伝送効率) ※ ファイルサイズはたいてい「バイト」で書かれている。 必ず ×8 して「ビット」に直すこと。

例題1(基本)

10Mバイトのファイルを、回線速度100Mbps・伝送効率80%の回線で送るのにかかる時間は?

① バイト→ビット 10Mバイト × 8 = 80Mビット ② 実効速度 100Mbps × 0.8 = 80Mbps ③ 伝送時間 80M ÷ 80M = 1秒

例題2(逆算)

1Gバイトのファイルを100秒で送りたい。回線利用率が50%のとき、必要な回線速度は?

① バイト→ビット 1Gバイト × 8 = 8Gビット ② 必要な実効速度 8Gビット ÷ 100秒 = 80Mbps ③ 回線速度 80Mbps ÷ 0.5 = 160Mbps

「実効速度 = 回線速度 × 利用率」なので、逆算するときは割る。

例題3(オーバーヘッド込み)

1パケットは データ部1000バイト + ヘッダ40バイト。1Mバイトのデータを送るとき、 実際に回線に流れる量と伝送効率は?

① パケット数 1Mバイト ÷ 1000バイト = 1000個 ② 実際の総量 1000個 × (1000 + 40) = 1,040,000バイト ③ 伝送効率 1000 ÷ 1040 ≒ 96.2%

ヘッダはデータではないが回線は使う。これがオーバーヘッド。

単位の落とし穴。
・バイト(B)とビット(b) … 大文字小文字で意味が変わる。MBはメガバイト、Mbはメガビット
・FEの計算では 1k=1000、1M=106、1G=109 で扱う問題が多い(1024ではない)
・「回線利用率」「伝送効率」「実効速度」と書いてあったら必ず掛ける

9-2. サブネットの計算

ホスト部のビット数 = 32 − プレフィックス長 割り当て可能なホスト数 = 2^(ホスト部のビット数) − 2 └─ ネットワークアドレスと ブロードキャストアドレスの分

例題4(ホスト数)

192.168.1.0/24 を 4 つのサブネットに分割したい。マスクと、各サブネットのホスト数は?

① 4個に分けるには? 2^2 = 4 → 2ビット借りる ② プレフィックス 24 + 2 = /26 ③ サブネットマスク 255.255.255.192 ④ ホスト部 32 − 26 = 6ビット ⑤ ホスト数 2^6 − 2 = 62台

例題5(ネットワークアドレスを求める)

IPアドレス 172.16.100.75、サブネットマスク 255.255.255.224 のとき、 ネットワークアドレスとブロードキャストアドレスは?

① マスクの第4オクテット 224 = 11100000 → /27 ② ブロック幅 256 − 224 = 32 ずつ区切られる 0 / 32 / 64 / 96 / 128 … ③ 75 はどのブロック? 64 ≦ 75 < 96 → 64のブロック ④ ネットワークアドレス 172.16.100.64 ⑤ ブロードキャスト 172.16.100.95(次のブロックの1つ前) ⑥ 使えるアドレス 172.16.100.65 〜 172.16.100.94(30台)

コツ:「256 − マスクの値」でブロック幅が出る。あとは対象のアドレスがどのブロックに入るかを見るだけ。

9-3. 稼働率の計算

稼働率 = MTBF ÷ (MTBF + MTTR) MTBF(平均故障間隔) … 壊れずに動いていた平均時間 MTTR(平均修理時間) … 直すのにかかる平均時間 直列(どちらか壊れたら止まる) 稼働率 = A × B 並列(どちらか動いていればOK) 稼働率 = 1 − (1 − A)(1 − B)

例題6

MTBF が 450時間、MTTR が 50時間の装置の稼働率は?

450 ÷ (450 + 50) = 450 ÷ 500 = 0.9(90%)

例題7

稼働率0.9の装置を(a)2台直列、(b)2台並列にしたときの全体の稼働率は?

(a) 直列 0.9 × 0.9 = 0.81 (b) 並列 1 − (1 − 0.9) × (1 − 0.9) = 1 − 0.1 × 0.1 = 1 − 0.01 = 0.99

直列は下がり、並列は上がる。冗長化(並列)すると信頼性が上がるのはこのため。

並列の式を丸暗記しない。「両方とも壊れる確率」を出して 1 から引くだけ。
壊れる確率 = 1 − 稼働率。だから「1 −(壊れる確率 × 壊れる確率)」。

9-4. 直前チェックリスト

  • OSI 7階層は上から アプ・セ・ト・ネ・デ・ブ
  • MACアドレスで振り分ける = L2スイッチ / IPアドレスで振り分ける = ルータ
  • ブロードキャストドメインを分割できるのは ルータ(スイッチではない)
  • 有線は CSMA/CD、無線は CSMA/CA
  • ホスト数は 2^ホスト部 − 2。「−2」を忘れない
  • TCP = 確実さ / UDP = 速さ。3ウェイハンドシェイクは SYN → SYN+ACK → ACK
  • ポート番号 … 22 SSH / 25 SMTP / 53 DNS / 80 HTTP / 110 POP3 / 443 HTTPS
  • DHCP は D→O→R→A。ARP は IP → MAC
  • ホップ数で選ぶ = RIP / コストで選ぶ・大規模 = OSPF / AS間 = BGP
  • NAT = アドレスだけ / NAPT = アドレス + ポート
  • 誤りを訂正までできるのは ハミング符号。パリティ・CRC・チェックサムは検出のみ
  • 検知だけ = IDS / 遮断まで = IPS
  • 公開サーバを置く中間地帯 = DMZ
  • 計算はまずバイト→ビット(×8)、そして利用率を掛ける
