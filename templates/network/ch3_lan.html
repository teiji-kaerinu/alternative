3. LAN・イーサネット・無線LAN

イーサネットの規格

読み方は「速度 BASE 媒体」。BASE はベースバンド伝送(デジタル信号をそのまま流す方式)の意味。

規格速度ケーブル
10BASE-T10Mbpsツイストペア(UTP)
100BASE-TX100Mbpsツイストペア(カテゴリ5以上)
1000BASE-T1Gbpsツイストペア(カテゴリ5e以上)
1000BASE-SX / LX1Gbps光ファイバ

ツイストペアケーブルは2本1組をより合わせてノイズを打ち消している。 シールドなしが UTP、シールドありが STP。

MACアドレス

  • 48ビット。16進数12桁で 00-1B-44-11-3A-B7 のように書く
  • 前半24ビット = ベンダID(OUI)。メーカーに割り当てられた番号
  • 後半24ビット = メーカー内の製造番号
  • NIC(LANカード)に製造時に焼き込まれているので、原則として世界中で重複しない
IPアドレスとの違い。MACアドレスは機器そのものに固定(引っ越しても変わらない)。 IPアドレスは繋いだ場所によって変わる。手紙で言えば MAC が「マイナンバー」、IP が「住所」。

イーサネットフレームの構造

[プリアンブル][宛先MAC][送信元MAC][タイプ][ データ ][FCS] 6バイト 6バイト 2バイト 46〜1500バイト 4バイト
  • FCS(Frame Check Sequence) … CRC による誤り検出用の値。壊れていたらフレームを捨てる
  • MTU … 1フレームで運べるデータの最大サイズ。イーサネットは通常1500バイト

アクセス制御方式(衝突対策)

CSMA/CDCSMA/CA
使う場所有線LAN(IEEE 802.3)無線LAN(IEEE 802.11)
CD / CACollision Detection(衝突検出)Collision Avoidance(衝突回避)
やり方回線が空いたら送る。衝突したらランダム時間待って再送回線が空いてもランダム時間待ってから送る。ACKで到達確認
なぜ違う—無線は送信中に他人の信号を聞けず、衝突を検出できないため、先に避ける
CSMA/CD は今は使われていない。スイッチングハブ + 全二重通信が主流になり、 そもそも衝突が起きない。試験では「昔の半二重イーサネットの技術」として出る。

スイッチングハブの動作

  1. フレームを受け取ると、送信元MACアドレスとポート番号を MACアドレステーブルに記録する(自己学習)
  2. 宛先MACがテーブルにあれば、そのポートだけに転送する
  3. テーブルに無ければ、受信ポート以外の全ポートに転送する(フラッディング)

転送方式には、フレーム全体を受け取ってから送るストアアンドフォワード(誤りを捨てられる)と、 宛先だけ読んですぐ送るカットスルー(速いが誤りも通す)がある。

VLAN(仮想LAN)

物理的な配線に関係なく、論理的にLANを分割する技術。 同じスイッチに繋がっていても、別のVLANなら直接通信できない(ルータやL3スイッチを経由する必要がある)。

  • ポートVLAN … スイッチのポート単位でグループ分けする
  • タグVLAN … フレームにVLAN識別子のタグを付ける(IEEE 802.1Q)。 1本のケーブルで複数VLANを運べる

メリット … 部署ごとに分けてセキュリティ向上、ブロードキャストの範囲を狭める、配線を変えずに構成変更できる。

無線LANの用語とセキュリティ

  • SSID / ESSID … アクセスポイントの名前。ステルス機能で名前を隠せる
  • MACアドレスフィルタリング … 登録した機器だけ接続を許可する。ただし偽装できるので万能ではない
  • インフラストラクチャモード … アクセスポイント経由で通信(普通のWi-Fi)
  • アドホックモード … 端末同士が直接通信する
  • ローミング … 移動しながらアクセスポイントを自動で切り替える
暗号化方式評価
WEP× 脆弱性があり使ってはいけない。短時間で解読される
WPA△ TKIP を採用。WEP の改良版だが現在は非推奨
WPA2○ AES(CCMP)を採用。現在の標準
WPA3◎ 最新。より強固な鍵交換(SAE)

その他

  • PoE(Power over Ethernet) … LANケーブルで電力も供給する。アクセスポイントや監視カメラの設置に便利(IEEE 802.3af/at)
  • リンクアグリゲーション … 複数のLANケーブルを束ねて1本に見せる。高速化と冗長化(IEEE 802.3ad)
  • スパニングツリープロトコル(STP) … スイッチをループ状に繋いだときのブロードキャストストームを防ぐ。 一部の経路を論理的に遮断しておき、障害時に開通させる(IEEE 802.1D)
